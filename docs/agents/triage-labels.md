# 任務分類字串

本機任務的 `Status:` 使用以下預設字串；不建立外部 GitHub 標籤。

| 技能分類 | 本機字串 | 意義 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待評估 |
| needs-info | needs-info | 等待補充資訊 |
| ready-for-agent | ready-for-agent | 規格完整，可由代理處理 |
| ready-for-human | ready-for-human | 需要人工處理 |
| wontfix | wontfix | 決定不處理 |

Wayfinder 的認領與結案狀態另用 `claimed`／`resolved`，依 [issue-tracker.md](issue-tracker.md) 操作。
